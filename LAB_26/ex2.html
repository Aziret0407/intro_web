Text Alignment and Line Height

Left Aligned (line-height: 1.2)

This text is aligned to the left. Line height is 1.2 which is compact. Good for short text where you want to save space.

Center Aligned (line-height: 1.5)

This text is centered. Line height is 1.5 which is standard for most websites. Good balance between readability and space.

Right Aligned (line-height: 1.8)

This text is aligned to the right. Line height is 1.8 which is spacious. Good for accessibility and easy reading.

Justified (line-height: 2.0)

This text is justified. Line height is 2.0 which is very spacious. Justified text creates straight edges on both sides, like in newspapers and books.
