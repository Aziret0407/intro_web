Z-Index Property Demonstration

Stacking Order with z-index

Elements with higher z-index appear on top:

Box 1
z-index: 1
Box 2
z-index: 2
Box 3
z-index: 3
Box 4
z-index: auto (default)

Note: Box 3 (green) has highest z-index (3) and appears on top. Box 1 (red) has lowest z-index (1) and appears at the bottom.

Complex Stacking Example

Background Layer
z-index: 1
Middle Layer
z-index: 2
Foreground Layer
z-index: 3
Negative Layer
z-index: -1

Z-Index Rules:

  • Higher z-index values appear on top of lower values
  • Elements with negative z-index appear behind parent elements
  • z-index only works on positioned elements (not static)
  • If z-index is not set, later elements appear on top of earlier ones
