Display Property Demonstration

1. display: block

Block elements take full width and start on new lines:

Block 1
Block 2
Block 3

2. display: inline

Inline elements sit next to each other:

Inline 1 Inline 2 Inline 3

Note: width/height have no effect on inline elements.

3. display: inline-block

Inline-block elements sit next to each other but respect width/height:

Box 1
Box 2
Box 3

4. display: none

This element is hidden using display: none:

This text will not be visible

The element above takes no space in the layout.

Display Values Summary:

ValueBehavior
blockFull width, starts new line
inlineOnly as wide as content, no width/height
inline-blockInline but respects width/height
noneElement completely hidden
